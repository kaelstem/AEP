# PSE em Ação

## Sobre o projeto

O PSE em Ação é um sistema desenvolvido em linguagem C para auxiliar no planejamento, registro e acompanhamento de ações coletivas relacionadas ao Programa Saúde na Escola (PSE).

## Objetivo

Organizar informações sobre as ações planejadas e realizadas, permitindo cadastro, listagem, pesquisa, atualização de situação e geração de um resumo das atividades.

## Funcionalidades

- Cadastro de ações
- Listagem de ações
- Pesquisa por código, escola ou tema
- Atualização da situação da ação
- Registro de participantes
- Geração de resumo
- Validação de dados

- `documentacao/` — documentos da Entrega 1
- `src/` — código-fonte do sistema
